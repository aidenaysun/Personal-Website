Direct Tutor

Node.js, React, PostgreSQL, AWS, Stripe — Jun. 2026–Present

A full-stack application that matches students with tutors based on user information. The frontend uses React and Vite and the backend uses Node.js. App data lives in PostgreSQL through Supabase, payments run through Stripe with webhooks, and automated email goes out through AWS SES, set up with the AWS CLI on Linux.
