YouTube Rewind Controller

JavaScript, HTML, CSS — Chrome Extension (published), July 2025

A Chrome extension built on Manifest V3 that adds a hotkey for continuous rewind of YouTube videos in small increments: hold R and playback steps back 0.2 s every 100 ms (tnew = max(0, tcurrent − Δt)).

It is event-driven. A background script watches tab updates and messages a content script, which handles keyboard input, DOM manipulation and timer-based state updates, and injects an overlay that shows when rewind is active. The result is low-latency, continuous playback reversal from a single key.
