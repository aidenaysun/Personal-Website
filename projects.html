YouTube Rewind Controller

JavaScript, HTML, CSS — Chrome Extension (published), July 2025

A Chrome extension built on Manifest V3 that adds a hotkey for continuous rewind of YouTube videos in small increments: hold R and playback steps back 0.2 s every 100 ms (tnew = max(0, tcurrent − Δt)). It is event-driven, with a background script that watches tab updates and messages a content script, which handles keyboard input, DOM manipulation, timer-based state updates, and an overlay that shows when rewind is active.

Assistive Notes Processor

Python — pdf2image, PIL, img2pdf

I built this after seeing classmates struggle to read lecture notes with impaired eyesight. It turns scanned or photographed handwritten notes into high-contrast, readable PDFs in three stages:

  • Rasterize each PDF page to a high-resolution PNG with pdf2image and Poppler.
  • Convert to grayscale with the luminance equation Y = 0.299R + 0.587G + 0.114B, then apply a global binary threshold (T ≈ 240) to remove uneven lighting, notebook lines, and shadows.
  • Reassemble the pages into a single PDF with img2pdf, which keeps resolution and color depth without recompression.
